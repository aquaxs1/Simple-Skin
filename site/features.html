Capabilities

What the mod can do

Skin library

Three tabs — History (the last 40 skins you wore), Change Skin (your saved wardrobe) and Steal Skin (everyone on the server). Cards show a live preview, where the skin came from and its hotkey. The skin you are wearing is outlined in green.

Equip without restarting

Equip from a card, from the settings screen, or from a per-skin hotkey. The texture is registered and applied on the spot. Nothing is written to your game files and nothing needs a relaunch.

Live sync to other players

When the server also runs Simple Skin, your swap is relayed to every other Simple Skin client straight away over the simple_skin:equip channel. Players who join later are caught up automatically. On a vanilla server the channel is never negotiated and nothing is sent.

Profile upload with verification

The fallback route uploads the PNG to your Minecraft profile, then polls Mojang and downloads the texture it actually serves, comparing it byte for byte. Only once it matches does a rejoin happen — the CDN lags behind, and reconnecting early would publish your old skin.

Steal from the server

Every player on the tab list can be copied with one click, either equipped straight away or saved to your wardrobe. Downloads are pinned to Mojang's texture host, so a hostile server cannot point the mod anywhere else.

Search any username

Type a name in the Steal tab and Simple Skin resolves it through Mojang's public API — the player does not need to be online, or on your server at all. NameMC is deliberately not used: it has no public API and its terms forbid scraping.

Import from your computer

Pick a PNG through your system's file chooser, or simply drop files into config/simple-skin/import — they are picked up automatically. Both 64×64 and legacy 64×32 skins are accepted and converted exactly the way the game converts them.

Built-in editor

Remove any second-layer overlay (hat, jacket, either sleeve, either trouser leg), graft the head of another saved skin onto this one, or replace one colour with another across the whole image. Every edit is saved as a new skin, so the original survives.

Outfits with capes

Pair a skin with a cape choice: keep the one you have, hide it, or wear a specific cape. Mojang only allows activating capes your account already owns — no mod can upload one — so the picker lists exactly what is on your profile.

Hotkeys, shuffle and rotation

Bind any key to any saved skin, with a warning when it clashes with a vanilla control. A separate shuffle key equips a random skin, and an optional timer rotates through your wardrobe while you play.

3D preview

The settings screen renders the skin on a real player model you can drag to rotate and tilt, so you can check the back and the arms before committing.

Export and delete

Write any stored skin back out as a PNG to .minecraft/simple-skin/exports, or remove it for good with a two-step confirmation. Deleting the skin you are wearing also drops the override.

Installation

Getting it running

Install Fabric for Minecraft 26.2

Run the Fabric installer, choose 26.2, and install. A new profile appears in the launcher — start the game once with it so the folders are created.

Drop in Fabric API

Download Fabric API for 26.2 and put the jar in .minecraft/mods.

Add Simple Skin

Put simple-skin-2.0.0.jar in the same mods folder.

Launch and press K

Join a world or a server, press K, and the library opens. Rebind the key under Options → Controls → Simple Skin if you like.

Optional: the server too

Copy the same jar into the server's mods folder (it needs Fabric Loader and Fabric API as well). Every player who also has the mod then sees skin swaps instantly.

How to use it

Driving the mod

Wear a skin

Press K → Change Skin → Equip. It applies instantly on your screen, then travels to the other players by whichever route is available. The status line at the bottom of the panel always says what is happening.

Take someone's skin

Open Steal Skin. Click Equip to wear it now, or Save to keep it. To grab someone who is not on the server, type their name in the search box and press Search.

Bind a hotkey

Open a skin's ⚙ settings → Quick equip → click, then press the key. Backspace clears it, Esc cancels. If the key is already used by a vanilla control or another skin, Simple Skin tells you.

Choose who sees it

The Visibility button cycles through Only me, Upload to profile and Upload + rejoin. The badge in the top-right of the library always shows the current setting.

Import a PNG

Either click Import PNG in the library, or drop files into .minecraft/config/simple-skin/import. Dropped files are picked up within a few seconds — a file is only read once its size stops changing, so a half-copied file is never imported.

Edit a skin

Settings → Edit skin. Remove layers, swap a head, or type two hex colours and press Replace colour. Press Save as new to keep the result; Reset throws the edits away.

Shuffle and rotate

Shuffle in the library equips a random saved skin. Bind the shuffle hotkey under Options → Controls, or set a rotation interval so it changes on its own while you play.

Pick a cape

Settings → Cape. Cycle to Pick cape and Simple Skin loads the capes your account owns. Choosing one changes it on your profile, so other players see it just like a new skin.

Where your files live

Everything stays inside your Minecraft folder.

  • config/simple-skin/skins.json — library metadata and settings
  • config/simple-skin/skins/ — stored skin PNGs
  • config/simple-skin/import/ — drop PNGs here to import them
  • simple-skin/exports/ — where Export PNG writes
