Frequently asked questions

How the mod behaves, what it cannot do, and what to check when something goes wrong.

General

The basics

Do other players actually see my new skin?

Yes. If the server runs Simple Skin too, the swap reaches everyone with the mod immediately. Otherwise the mod uploads the skin to your Minecraft profile and rejoins, so the server re-reads it and even players without the mod see it — at that point it is simply your real skin.

Why does it need to rejoin the server?

Other players ask the server what your skin is, and the server asks Mojang once, while you log in. Reconnecting is the only client-side way to trigger that again. You can turn the automatic rejoin off, or set visibility to Only me and skip it.

Does it work in single player?

Yes, and the rejoin step is skipped — there is nobody to show it to.

Do I need the mod on the server?

No. A plain vanilla server is fine. Server-side it only adds live sync, which makes swaps instant.

Can I use it in offline mode?

Partly. Without an online session there is no profile to upload to, so the skin applies on your screen only — the status line says so. Live sync still works if the server runs the mod.

Skins & capes

What you can wear

Can I upload a custom cape?

No. Capes come from your Mojang account, so the mod can only pick between the ones you already own. Custom capes are visible to other players with the mod through live sync.

What image sizes are accepted?

64×64 for skins, and both the classic and slim models. 64×32 legacy skins are converted on import.

Is stealing someone's skin allowed?

Skins are public through the Mojang API, so fetching one is not an exploit. Whether wearing it is welcome is a matter for the server rules.

Does the editor overwrite my original skin?

No. Edits are saved as a new entry in your library; the original stays untouched.

Safety

Accounts and servers

Can I get banned for this?

Changing your own skin is a normal account action, but automation and impersonation are judged by each server. Check the rules of the servers you play on — that call is theirs, not ours.

Where does my session token go?

Nowhere. It stays in your game and is used only against Mojang's own API. The mod contacts no server of ours; there is none.

Is it safe to run on a public server?

The mod sends no packets of its own unless the server also runs it. With live sync it exchanges only the skin data needed to draw you.

Troubleshooting

When it does not work

The game will not start after adding the mod

Almost always a version mismatch: it needs Minecraft 26.2, Java 25, Fabric Loader 0.19.3+ and Fabric API. The crash log names the one that is missing.

Pressing K does nothing

Another mod has taken the key. Rebind it under Options → Controls → Simple Skin.

"Mojang is rate limiting skin changes"

Mojang caps how often a profile skin may change. Wait a few minutes; the mod retries on its own.

"Uploaded, but Mojang is still serving the old skin"

Their CDN is caching. The mod waits for the new skin before rejoining, so this resolves itself.

A file in the import folder is ignored

It is not a valid 64×64 or 64×32 PNG. Convert it and drop it in again — the folder is re-read on open.

Live sync is not working

It needs the mod on the server and on the other player's client. Without both, the profile-upload route is used instead.
