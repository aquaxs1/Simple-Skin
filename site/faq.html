Frequently asked questions

How the mod behaves, what it cannot do, and what to check when something goes wrong.

General

The basics

Do other players actually see my new skin?

Yes — and this is the part most skin changers skip.

If the server also runs Simple Skin, the swap is relayed to every other player with the mod immediately, with no rejoin.

On a normal server the mod uploads the skin to your Minecraft profile, waits until Mojang really serves it, and then rejoins so the server re-reads your profile and tells everyone. Players without the mod see it too, because at that point it is simply your real skin.

Why does it need to rejoin the server?

Because a client-side mod cannot tell someone else's game what to draw. Every other player asks the server what your skin is, and the server asks Mojang exactly once — while you are logging in. Reconnecting is the only client-side way to make that happen again.

You can turn the automatic rejoin off and press Rejoin now yourself, or set visibility to Only me and skip it entirely.

Does it work in single player?

Yes. The skin applies locally exactly the same way. There is nobody else to show it to, so the rejoin step is skipped automatically.

Do I need the mod on the server?

No. Everything works on a plain vanilla server. Adding it server-side only unlocks live sync, which makes swaps instant instead of needing a rejoin.

Can I use it in offline mode?

Partly. Without an online session there is no profile to upload to, so the skin applies on your own screen only. The mod says so in the status line rather than pretending it worked.

Live sync does still work offline, as long as the server runs Simple Skin.

Skins & capes

What you can wear

Can I upload a custom cape?

No, and neither can any other mod. Mojang only lets an account activate a cape it already owns. Simple Skin lists the capes on your profile and lets you keep, hide, or switch between them.

Anything claiming to give you a custom cape either only shows it on your own screen, or is showing it to other users of that same mod.

What image sizes are accepted?

64×64 PNGs, and legacy 64×32 skins which are converted using Minecraft's own conversion. Anything else is rejected with a message. Files over 512 KB are refused before they are read.

Is stealing someone's skin allowed?

The mod only downloads skins that Mojang already serves publicly — the same picture any player can see by looking at that person in-game. Whether wearing it is welcome is a social question, and some servers have rules about impersonating other players. Use it kindly.

Does the editor overwrite my original skin?

Never. Every edit is saved as a new entry in your library. Reset throws the working copy away and goes back to the original.

Safety

Accounts and servers

Can I get banned for this?

The mod uses Mojang's own public endpoints and does exactly what the official skin page does — nothing is spoofed or faked. It gives no gameplay advantage.

That said, individual servers set their own rules. Changing skin repeatedly, or dressing up as another player, may break a server's rules even though the mod itself is doing nothing improper. Check before you go wild on someone else's server.

Where does my session token go?

Only to api.minecraftservices.com, Mojang's own endpoint, and only to upload a skin or change your active cape. It is never written to disk by the mod and never sent anywhere else. There is no analytics, no telemetry and no third-party server involved.

Is it safe to run on a public server?

Skins that arrive over live sync are validated on both the server and the receiving client before being decoded — the payload is capped and rejected unless it is a real skin. Skin URLs are pinned to Mojang's texture host, so a hostile server cannot make the mod fetch from anywhere else.

Troubleshooting

When it does not work

The game will not start after adding the mod

Almost always a version mismatch. Check that you are on Minecraft 26.2 with Java 25, Fabric Loader 0.19.3+, and that Fabric API for 26.2 is in the same mods folder. The crash log names whichever one is missing.

Pressing K does nothing

Another mod may have taken the key. Open Options → Controls → Simple Skin and rebind it. The library also only opens once you are in a world or on a server.

"Mojang is rate limiting skin changes"

Mojang limits how often a profile skin can change. Wait a minute and try again. Repeated uploads of the same skin are skipped automatically, so holding a hotkey will not trip the limit.

"Uploaded, but Mojang is still serving the old skin"

The upload worked but Mojang's CDN had not caught up within the check window. The skin will appear for others shortly; press Rejoin now a little later, or reconnect normally.

A file in the import folder is ignored

Files that are not valid skins are renamed with a .rejected suffix so they are not retried forever. Check the size is 64×64 (or 64×32) and that it is really a PNG. The game log has the exact reason.

Live sync is not working

Both the server and the other player need Simple Skin installed. If the server does not have it, the channel is never negotiated and the mod silently falls back to the profile route — which is working as designed, just slower.
