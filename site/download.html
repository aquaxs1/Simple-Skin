Before it loads

What it needs

required

Minecraft 26.2

Built against 26.2 exactly. Earlier versions use a different, incompatible client API.

required

Java 25

Minecraft 26.2 needs it, and so does this mod. Older Java refuses to start the game.

required

Fabric Loader 0.19.3+

Install it with the Fabric installer, then pick the Fabric profile in the launcher.

required

Fabric API 0.158.0+26.2

From Modrinth or CurseForge, into the same mods folder.

optional

The same jar on the server

Server-side it unlocks live sync, so skin swaps reach other players without a rejoin. Everything else works without it.

check

Verify the file

Each release lists the SHA-256 of its jar. On Windows: certutil -hashfile <file> SHA256.
